# RuneWeaver

Synthesizes a collaborative environment for multiple developers to work together on open-source projects in real-time.

The key benefits of using RuneWeaver include:

- Synthesizes a collaborative environment for
- multiple developers to work together
- on open-source projects in real-time

## Technology Stack

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/RuneWeaver.git`
2. `cd RuneWeaver`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure RuneWeaver, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
